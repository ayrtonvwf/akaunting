**Optional; not included in this checkout**

This page is vocabulary only. None of the capabilities below should be assumed to have an implementation in this local source checkout. The [Help Centre category index](https://akaunting.com/hc/docs/) is the inventory that places these areas alongside the core product reference.

## Human Resource Management

Human Resource Management uses **employees**, **payroll**, and **payslips** to describe people and their pay activity. It connects people and payroll activity to the administration vocabulary, including company context and access. Its implementation is absent from this checkout. [Human Resource Management](https://akaunting.com/hc/docs/human-resource-management/) provides the Help Centre category context.

## CRM

CRM uses **contacts**, **companies**, **deals**, and the **customer journey** to describe relationship and opportunity activity. Where context requires it, CRM contacts should be distinguished from core sales customers, even when the same party is relevant to both. Its implementation is absent from this checkout. [CRM](https://akaunting.com/hc/docs/crm/) provides the Help Centre category context.

## Project Management

Project Management uses **projects**, **tasks**, **milestones**, **time**, and **billing** to describe customer-facing work. That work can lead to invoices, linking the optional project vocabulary to core sales documents. Its implementation is absent from this checkout. [Project Management](https://akaunting.com/hc/docs/project-management/) provides the Help Centre category context.

## Inventory Management

Inventory Management uses **stock**, **warehouses**, **item groups**, **variants**, **adjustments**, and **transfer orders** to describe inventory activity. It extends the core **item** vocabulary with quantities, locations, and related stock organization. Its implementation is absent from this checkout. [Inventory Management](https://akaunting.com/hc/docs/inventory-management/) provides the Help Centre category context.

## Double-Entry Accounting

Double-Entry Accounting uses a **chart of accounts**, **manual journals**, a **ledger**, **balance sheet**, and **trial balance** to describe accounting structure and views. It supplements the operational records and reports documented in the core reference. Its implementation is absent from this checkout. [Double-Entry Accounting](https://akaunting.com/hc/docs/double-entry-accounting/) provides the Help Centre category context.

## Helpdesk

Helpdesk uses **tickets**, **import**, **search**, **filter**, **status**, and **replies** to describe support activity. These terms provide a support vocabulary that is separate from core financial records while still using familiar interchange and discovery language. Its implementation is absent from this checkout. [Helpdesk](https://akaunting.com/hc/docs/helpdesk/) provides the Help Centre category context.

## Receipts

Receipts uses **receipt creation** and **receipt editing** to describe evidence associated with transactions or expenses. Receipt vocabulary therefore relates to core transaction and expense records without replacing them. Its implementation is absent from this checkout. [Receipts](https://akaunting.com/hc/docs/receipts/) provides the Help Centre category context.

## Related concepts

These optional terms extend the shared **company**, **contact**, **item**, **document**, and **payment** vocabulary defined in [concepts](concepts.md). The core pages for [sales](sales.md), [purchases](purchases.md), [banking](banking.md), [reporting](reporting.md), and [administration](administration.md) describe the local product concepts to which these optional terms relate. The [Help Centre category index](https://akaunting.com/hc/docs/) supplies the source inventory for the categories represented here.
